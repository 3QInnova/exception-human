# EXCEPTION: HUMAN

A browser rage platformer starring a confidently wrong AI. Friends playtest, October 13, 2026.

Open `index.html` to choose PC or iPhone Safari. `desktop.html` and `mobile.html` are self-contained HTML/CSS/JavaScript game source, with no API keys, libraries, or downloaded assets.

## GitHub Pages

Publish from `main`, repository root. Playtest URL: https://3qinnova.com/exception-human/ (the account Pages site uses this custom domain).

## Controls

PC: A/D or arrows move, Space jumps, X rewrites, R retries. iPhone: landscape Safari, left thumb movement, right thumb Jump/Rewrite. Tap an AI remark to pause and read. The menu offers floor-hint and long-level practice. Some caution tiles bounce you into a Git secret-scanning block; jump over those tiles.

Loss reading lasts 15 seconds; two Continue taps skip it. Compaction deliberately interrupts progress for 15 seconds. Random AI billing dialogs ask for imaginary credits or renewals; choose the free plan and confirm to resume. No real payments are involved.

## Feedback

Tell Will your device/browser, where you got stuck, what felt funny or unfair, and whether you would play again. There is no automatic gameplay feedback collection.

## Scope

The iPhone Safari controls and zoom fixes have been confirmed by the project owner. WebKit checks and an ordinary-input route through all nine rooms passed. Android and native iOS builds have not been tested.

The repository and Pages link are public; share the link with the selected friend group. Crawler metadata is not access control.
